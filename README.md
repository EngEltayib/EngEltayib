## 🔥 Engineering Principles

- Build first, abstract second.
- Keep state as local as possible.
- Prefer explicit code over clever code.
- Understand the browser, not only the framework.
- Learn Git as an engineering tool, not a save button.
- Treat loading, errors and empty states as product features.
- Design APIs and UI flows around real user states.
- Debug the cause, not the symptom.
- AI can accelerate engineering — it should never replace understanding.
